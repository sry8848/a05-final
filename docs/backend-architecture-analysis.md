# 后端项目架构分析文档

## 1. 项目概览

这是一个基于Spring Boot 3.2.5的AI模拟面试系统后端，使用Java 21开发，集成了多种现代技术栈，包括AI能力、语音识别、知识库检索等功能。

## 2. 技术栈分析

| 类别 | 技术/框架 | 版本 | 用途 |
|------|-----------|------|------|
| 基础框架 | Spring Boot | 3.2.5 | 应用主框架 |
| 数据库 | MySQL | - | 关系型数据库 |
| ORM | MyBatis-Plus | 3.5.5 | 数据库访问 |
| 缓存 | Redis | - | 缓存、会话管理 |
| 消息队列 | RabbitMQ | - | 异步消息处理 |
| 安全 | Spring Security + JWT | - | 认证与授权 |
| AI集成 | Spring AI + OpenAI兼容API | 1.0.0 | AI能力集成 |
| RAG | Qdrant | - | 向量数据库，知识库检索 |
| 语音服务 | 阿里云ASR/TTS | - | 语音识别与合成 |
| 文档处理 | PDFBox + POI | 3.0.3 / 5.2.5 | 简历解析 |
| API文档 | Swagger | 2.2.20 | 接口文档 |
| 响应式 | WebFlux | - | SSE流式支持 |

### 3.2 模块功能分析

#### 3.2.1 管理后台模块 (`admin/`)
- **功能**：管理后台相关功能，包括仪表盘和安全管理
- **核心组件**：
  - `dashboard/`：管理后台仪表盘
  - `security/`：管理后台安全认证

#### 3.2.2 AI模块 (`ai/`)
- **功能**：AI调用核心模块，集成OpenAI兼容API
- **核心组件**：
  - `config/`：AI相关配置
  - `contract/`：AI调用契约定义
  - `dto/`：AI输入输出数据传输对象
  - `entity/`：AI调用日志实体
  - `impl/`：AI客户端实现（真实和模拟）
  - `prompt/`：提示词模板管理
  - `service/`：AI调用服务

#### 3.2.3 认证模块 (`auth/`)
- **功能**：用户认证与授权
- **核心组件**：
  - `config/`：认证相关配置（JWT、安全配置）
  - `dto/`：认证相关数据传输对象
  - `entity/`：用户实体
  - `service/`：认证服务、邮件发送服务

#### 3.2.4 面试核心模块 (`interview/`)
- **功能**：面试流程核心逻辑
- **核心组件**：
  - `debug/`：面试调试工具
  - `dto/`：面试相关数据传输对象
  - `engine/`：面试引擎核心
  - `entity/`：面试相关实体
  - `event/`：面试相关事件
  - `mapper/`：面试相关数据访问
  - `service/`：面试相关服务

#### 3.2.5 知识库模块 (`rag/`)
- **功能**：基于向量数据库的知识库检索
- **核心组件**：
  - `config/`：RAG配置
  - `controller/`：知识管理接口
  - `data/`：示例数据加载
  - `dto/`：RAG相关数据传输对象
  - `service/`：知识摄入、检索服务

#### 3.2.6 语音服务模块 (`speech/`)
- **功能**：语音识别与合成
- **核心组件**：
  - `config/`：语音服务配置
  - `dto/`：语音服务数据传输对象
  - `service/`：ASR（语音识别）和TTS（语音合成）服务

#### 3.2.7 其他模块
- **position/**：职位管理
- **profile/**：用户档案管理
- **questionbank/**：题库管理
- **resume/**：简历管理
- **system/**：系统管理

## 4. 核心功能流程

### 4.1 面试流程
1. 用户创建面试
2. 系统生成面试问题（通过AI）
3. 用户回答问题
4. 系统评估回答（通过AI）
5. 生成面试报告（通过AI）
6. 提供学习建议

### 4.2 认证流程
1. 用户注册/登录
2. 系统发送验证码（邮件）
3. 用户验证
4. 系统生成JWT令牌
5. 用户使用令牌访问受保护资源

### 4.3 AI调用流程
1. 准备AI输入
2. 加载提示词模板
3. 调用AI服务
4. 处理AI响应
5. 记录调用日志

### 4.4 知识库检索流程
1. 接收检索请求
2. 向向量数据库查询相关知识
3. 对结果进行重排序
4. 返回检索结果

## 9. 总结

该后端项目是一个功能完整、技术先进的AI模拟面试系统，采用了现代Java技术栈和架构设计。其核心优势在于：

1. **技术先进性**：集成了AI、RAG、语音服务等前沿技术
2. **架构合理性**：模块化设计，职责清晰，易于扩展
3. **功能完整性**：涵盖了面试全流程的各个环节
4. **代码质量高**：完善的测试覆盖和代码规范
5. **配置灵活性**：支持多环境配置和灵活的参数调整

该项目为Java后端开发提供了一个很好的学习范例，展示了如何构建一个现代化、功能完整的企业级应用。
