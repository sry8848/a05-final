# 当前产品范围

本文只描述 2026-03-25 当前工作区已经存在的产品能力，不写历史设想和未来路线。

## 产品定位

这是一个 AI 模拟面试系统，核心目标是把以下能力串成一条可联调的链路：

1. 用户登录并维护简历
2. 用户创建面试会话
3. 系统生成考纲并进入逐题问答
4. 每题提交后由后端评估并通过 SSE 生成下一题
5. 面试结束后异步生成报告
6. 用户查看历史、单题复盘、成长数据和问答库

## 当前主流程

### 用户端

1. 登录或注册
2. 进入成长中心
3. 在“开始面试”页完成准备配置
4. 在同一页面内完成设备检测与加载阶段
5. 进入面试中的问答流程
6. 查看报告、历史、单题详情、成长问答库

### 管理端

1. 管理员登录
2. 进入仪表盘
3. 查看 Prompt、模型路由、RAG 管理、系统监控、数据分析等页面

## 当前已落地能力

### 账户与鉴权

- 邮箱注册
- 邮箱密码登录
- 邮箱验证码登录
- 普通用户登录态恢复与退出
- 管理员登录、鉴权与退出

### 简历与个人中心

- 简历上传、解析状态轮询、详情查看、编辑、设默认、删除
- 用户资料读取与更新
- 头像上传与头像文件读取
- 成长统计与知识域概览

### 面试主链路

- 创建面试会话
- 保存最近一次面试偏好
- 会话详情轮询
- 逐题提交回答：`POST /interviews/{sessionId}/attempts`
- 实时题目流：`GET /interviews/{sessionId}/questions/stream?attemptId=...`
- 结束面试并触发报告生成
- 报告查询
- 单题详情查询
- 单题重答与最近一次重答查询
- 历史列表查询
- 状态账本调试接口

### 复盘与成长

- 单题详情页展示详细评估
- 问答库收藏、分页查询、删除
- 报告页学习建议查询
- 历史记录列表与报告回看

### 语音与流式体验

- ASR 票据下发
- ASR 停顿阈值配置查询
- SSE 实时题目文本流
- 题目播报音频状态查询与音频下载
- 片段 TTS 音频下载

### 管理端与 RAG

- 管理端仪表盘四类接口：概览、趋势、模型、Prompt 摘要
- 条件启用的知识入库接口：`POST /admin/knowledge/ingest`
- RAG 检索、Qdrant 配置与样本数据初始化能力

## 当前前端形态

- 用户端当前是单页状态切换应用，不是基于 Vue Router 的多路由站点
- “面试准备 / 设备检测 / 加载 / 面试中”目前都在 `InterviewPage` 内部切换
- 报告页、单题详情页、雷达图页、趋势页属于 overlay 或临时全屏页

详细入口见 [page-list.md](/D:/a05-cursor/docs/page-list.md)。

## 当前 AI 编排边界

- `planner`：创建会话后生成考纲
- `evaluation-decision`：评估当前回答并输出下一步决策
- `question-generation-stream`：按决策实时生成下一题题干
- `question-detail-evaluation`：生成单题复盘结果
- `report-generation`：生成整场报告
- `intro-rewrite`：首题措辞改写

详细职责见 [prompt-strategy.md](/D:/a05-cursor/docs/prompt-strategy.md)。
