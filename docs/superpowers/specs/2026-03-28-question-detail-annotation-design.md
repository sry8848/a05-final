# 问答详情页批注视觉改版设计

- 日期：2026-03-28
- 页面：[QuestionDetailPage.vue](D:/a05-cursor/frontend/src/components/QuestionDetailPage.vue)
- 目标：提升“我的回答”区域的可读性，降低红绿批注的视觉噪声，让批注回到辅助说明而不是主视觉。

## 背景

当前问答详情页存在两个直接影响阅读的问题：

1. `我的回答` 文本容器底色偏深，正文与高亮色的对比不足，整段阅读发灰。
2. 命中片段同时使用高饱和字体色和背景色，导致亮点与问题片段像整块涂色，批注感过重。
3. 下方亮点/待补强说明直接使用高饱和纯绿、纯红文字，视觉层级甚至超过正文。

这三个问题叠加后，页面更像“颜色警报面板”，而不是帮助用户复盘答案的教学界面。

## 设计目标

1. 正文优先：用户首先应该顺畅读完答案，再感知哪些位置被批注。
2. 颜色克制：红绿只作为强调信号，不再承担整段背景标识。
3. 未命中文本保持自然：只有真正被 AI 标记的片段才需要视觉强调。
4. 批注说明降噪：下方说明需要清楚，但不能再和正文抢视觉焦点。

## 方案结论

采用“方案 1：浅白正文框 + 仅片段字体着色 + 轻量批注卡”。

核心规则：

1. `我的回答` 文本框改为浅白底，搭配轻灰蓝边框和轻阴影，恢复正文可读性。
2. 普通正文统一使用默认深色文字，不再默认染红染绿。
3. 命中的 `highlightedSegments` 只通过字体颜色和适度字重强调，不再使用背景高亮。
4. 下方批注说明改为浅底卡片，正文使用深色文本，颜色只保留在图标和轻量辅助信息上。

## 具体视觉规范

### 1. 我的回答正文框

- 背景：白色或极浅冷白色。
- 边框：低对比灰蓝边框，用来和页面玻璃卡片区分。
- 阴影：轻阴影即可，避免卡片悬浮感过强。
- 正文字色：深灰蓝，保证长段中文阅读清晰。
- 行高：维持当前偏宽松阅读节奏，保证复盘时不拥挤。

### 2. 亮点 / 待补强片段

- 仅对被命中的片段渲染强调色。
- `strength`：使用较深的青绿色，不使用荧光绿，不铺背景。
- `weakness`：使用较深的暖红色，不使用亮粉红，不铺背景。
- 允许增加轻微字重，但不使用过粗字体，避免破坏正文节奏。
- 未命中的文字保持默认正文颜色，不附加任何特殊背景。

### 3. 下方批注说明

- 由“纯色文本列表”改为“浅底提示卡列表”。
- 正向说明：浅绿色背景、深色正文、绿色图标。
- 负向说明：浅红色背景、深色正文、红色图标。
- 说明文字本体不再使用高饱和纯绿/纯红，优先保证可读性。
- 批注卡与正文框之间保留明确间距，使其视觉上属于“解释层”而不是“正文层”。

## 实现范围

本次只处理问答详情页单题复盘中的批注视觉，不修改后端数据结构，不修改评估结果生成逻辑。

包含：

1. 调整 `QuestionDetailPage.vue` 中“我的回答”区域和批注说明区域样式。
2. 保持 `renderSegments` 的数据映射逻辑基本不变，仅改变渲染表现。
3. 必要时微调顶部辅助文案，例如将“绿色为亮点，红色为待补强片段”调整得更贴近新表现方式。

不包含：

1. 重新设计整页布局。
2. 修改 `highlightedSegments` 数据来源或标注策略。
3. 批量改动其他页面的高亮体系。

## 风险与取舍

### 风险

1. 如果强调色压得过轻，用户可能不容易一眼看出被标注的片段。
2. 如果批注卡做得过重，又会重新抢走正文注意力。

### 对应控制

1. 通过“更稳的深色强调 + 适度字重”补足去背景后的识别度。
2. 批注卡仅保留浅底和图标，不做大面积高饱和文字。

## 验收标准

满足以下条件即可视为本次改版达标：

1. `我的回答` 区域在默认页面背景上明显更易读，不再出现“灰底看不清”。
2. 正文中只有命中片段出现红/绿强调，其余文本保持正常颜色。
3. 命中片段没有整块背景高亮。
4. 下方亮点/待补强说明较当前明显更柔和，但仍可快速区分正负向。
5. 页面构建和相关测试通过。
