## 3. 当前差异清单（按优先级）

## 8. Spring AI 迁移方案（替换 AiClient 实现层）

### 8.1 迁移目标与原则

**目标**：用 Spring AI 1.0 替换当前 `OpenAiClient` 中手工拼装 HTTP 请求、正则提取 JSON、手动统计 Token 的脆弱实现，同时保持 `AiClient` 接口不变，对上层服务零感知。

**原则**：

- `AiClient` 接口、所有 DTO（`PlannerInput/Output`、`QuestionGenerationInput/Output`）、`MockAiClient` 全部保留，只替换 `OpenAiClient` 内部实现
- 每一步可独立验证，出问题可单步回滚
- 新增 `callQuestionGenerationStream()` 流式方法时，在接口层同步扩展

**改动总览**：

```
AiClient 接口          ← 扩展：新增 callQuestionGenerationStream() + AiCallResult 包装
OpenAiClient           ← 核心替换：WebClient → Spring AI ChatClient
MockAiClient           ← 小改：新增 stream 方法的 mock 实现
pom.xml                ← 新增 spring-ai-openai-spring-boot-starter
application.yml        ← 迁移 ai.openai.* → spring.ai.openai.*
PlannerOrchestrationService / FirstQuestionGenerationService  ← 取 token 数写审计日志
```

---

### 8.2 依赖变更（pom.xml）

在 `<dependencyManagement>` 中引入 Spring AI BOM，在 `<dependencies>` 中新增 Starter：

```xml
<!-- 在 <dependencyManagement><dependencies> 中新增 -->
<dependency>
    <groupId>org.springframework.ai</groupId>
    <artifactId>spring-ai-bom</artifactId>
    <version>1.0.0</version>
    <type>pom</type>
    <scope>import</scope>
</dependency>

<!-- 在 <dependencies> 中新增 -->
<dependency>
    <groupId>org.springframework.ai</groupId>
    <artifactId>spring-ai-openai-spring-boot-starter</artifactId>
</dependency>
```

> `spring-boot-starter-webflux` 保留不动，SSE 流式接口仍需要它。
> `spring-ai-openai-spring-boot-starter` 支持 OpenAI-compatible 协议，DeepSeek / 通义千问等只需改 `base-url` 即可切换。

---

### 8.3 配置变更（application.yml）

**移除旧配置**（由 Spring AI 标准配置接管）：

```yaml
# 删除这段
ai:
  openai:
    api-key: ${OPENAI_API_KEY}
    base-url: https://api.openai.com
    model: gpt-4o-mini
    mock-enabled: false
```

**新增 Spring AI 配置**：

```yaml
spring:
  ai:
    openai:
      api-key: ${OPENAI_API_KEY}
      base-url: ${OPENAI_BASE_URL:https://api.openai.com}
      chat:
        options:
          model: ${OPENAI_MODEL:gpt-4o-mini}
          temperature: 0.7

# mock 开关保留，MockAiClient 仍用此属性条件激活
ai:
  openai:
    mock-enabled: ${AI_MOCK_ENABLED:true}
```

### 8.4 Step 1：新增 AiCallResult 包装类（ai/dto/AiCallResult.java）

**目的**：让 `AiClient` 接口在返回业务结果的同时，顺带把 token 数和耗时带出来，直接填入 `AiInvocationLog`，彻底消除现有表里 `request_tokens`/`response_tokens` 为 null 的问题。

package com.a05.aiinterview.ai.dto;

import lombok.Builder;
import lombok.Data;

/**
 * AI 调用结果包装类，同时携带业务输出与可观测性指标。
 *
 * @param <T> 业务输出类型，如 PlannerOutput / QuestionGenerationOutput

@Data
@Builder
public class AiCallResult<T> {

    /** 业务输出对象 */
    private T output;

    /** 输入 token 数，来自模型响应的 Usage 元数据 */
    private int promptTokens;

    /** 输出 token 数，来自模型响应的 Usage 元数据 */
    private int responseTokens;

    /** 端到端耗时（毫秒），由调用方计时后写入 */
    private long latencyMs;
}

### 8.6 Step 3：重写 OpenAiClient（核心替换）

用 `ChatClient` + `BeanOutputConverter` 替换全部手工 HTTP 调用与正则 JSON 提取。

```java
package com.a05.aiinterview.ai.impl;

import com.a05.aiinterview.ai.AiClient;
import com.a05.aiinterview.ai.dto.*;
import lombok.extern.slf4j.Slf4j;
import org.springframework.ai.chat.client.ChatClient;
import org.springframework.ai.chat.model.ChatModel;
import org.springframework.ai.chat.model.ChatResponse;
import org.springframework.ai.converter.BeanOutputConverter;
import org.springframework.boot.autoconfigure.condition.ConditionalOnProperty;
import org.springframework.stereotype.Component;
import reactor.core.publisher.Flux;

/**
 * AiClient 的 Spring AI 实现，当 ai.openai.mock-enabled=false 时激活。
 * 底层使用 Spring AI ChatClient，支持 OpenAI 及所有 OpenAI-compatible 供应商。
 */
@Slf4j
@Component
@ConditionalOnProperty(name = "ai.openai.mock-enabled", havingValue = "false")
public class OpenAiClient implements AiClient {

    private static final String PLANNER_SYSTEM_PROMPT = """
            你是一名经验丰富的技术面试官，擅长设计面试考纲。
            请根据候选人信息生成结构化的面试考纲，严格按照指定 JSON 格式输出，不要输出任何额外文字。
            """;

    private static final String QUESTION_GEN_SYSTEM_PROMPT = """
            你是一名技术面试官，正在进行一场模拟面试，现在需要出一道面试题。
            请严格按照指定 JSON 格式输出题目，不要输出任何额外文字。
            """;

    private static final String QUESTION_GEN_STREAM_SYSTEM_PROMPT = """
            你是一名技术面试官，正在进行一场模拟面试，现在需要出一道面试题。
            请用自然语言直接说出题目，语气口语化，不要输出 JSON 格式，不要有任何前言。
            """;

    private final ChatClient chatClient;
    private final BeanOutputConverter<PlannerOutput> plannerConverter;
    private final BeanOutputConverter<QuestionGenerationOutput> questionGenConverter;

    public OpenAiClient(ChatModel chatModel) {
        this.chatClient = ChatClient.create(chatModel);
        this.plannerConverter = new BeanOutputConverter<>(PlannerOutput.class);
        this.questionGenConverter = new BeanOutputConverter<>(QuestionGenerationOutput.class);
    }

    @Override
    public AiCallResult<PlannerOutput> callPlanner(PlannerInput input) {
        log.info("调用 Planner, positionCode={}, experienceLevel={}", input.getPositionCode(), input.getExperienceLevel());
        long startMs = System.currentTimeMillis();

        // BeanOutputConverter 自动在 Prompt 末尾注入 JSON schema 格式指令
        String userPrompt = buildPlannerUserPrompt(input) + "\n\n" + plannerConverter.getFormat();

        ChatResponse response = chatClient.prompt()
                .system(PLANNER_SYSTEM_PROMPT)
                .user(userPrompt)
                .call()
                .chatResponse();

        String content = response.getResult().getOutput().getContent();
        try {
            PlannerOutput output = plannerConverter.convert(content);
            log.info("Planner 调用成功，知识域数={}", output.getDomains() != null ? output.getDomains().size() : 0);
            return buildResult(output, response, startMs);
        } catch (Exception e) {
            log.error("Planner 响应解析失败, content={}", content, e);
            throw new RuntimeException("Planner AI 响应解析失败: " + e.getMessage(), e);
        }
    }

    @Override
    public AiCallResult<QuestionGenerationOutput> callQuestionGeneration(QuestionGenerationInput input) {
        log.info("调用出题, domainCode={}, questionType={}", input.getNextDomainCode(), input.getNextQuestionType());
        long startMs = System.currentTimeMillis();

        String userPrompt = buildQuestionGenUserPrompt(input) + "\n\n" + questionGenConverter.getFormat();

        ChatResponse response = chatClient.prompt()
                .system(QUESTION_GEN_SYSTEM_PROMPT)
                .user(userPrompt)
                .call()
                .chatResponse();

        String content = response.getResult().getOutput().getContent();
        try {
            QuestionGenerationOutput output = questionGenConverter.convert(content);
            log.info("出题成功, stem 长度={}", output.getStem() != null ? output.getStem().length() : 0);
            return buildResult(output, response, startMs);
        } catch (Exception e) {
            log.error("出题响应解析失败, content={}", content, e);
            throw new RuntimeException("出题 AI 响应解析失败: " + e.getMessage(), e);
        }
    }

    @Override
    public Flux<String> callQuestionGenerationStream(QuestionGenerationInput input) {
        log.info("流式出题, domainCode={}, questionType={}", input.getNextDomainCode(), input.getNextQuestionType());

        // 流式场景使用自然语言 prompt，无需 JSON 格式指令
        String userPrompt = buildQuestionGenUserPrompt(input);

        return chatClient.prompt()
                .system(QUESTION_GEN_STREAM_SYSTEM_PROMPT)
                .user(userPrompt)
                .stream()
                .content();
    }

    /**
     * 从 ChatResponse 的 Usage 元数据构建 AiCallResult 包装对象。
     * Usage 字段为 null 时（部分兼容供应商不返回）安全降级为 0。
     */
    private <T> AiCallResult<T> buildResult(T output, ChatResponse response, long startMs) {
        var usage = response.getMetadata().getUsage();
        int promptTokens = (usage != null && usage.getPromptTokens() != null)
                ? usage.getPromptTokens().intValue() : 0;
        int responseTokens = (usage != null && usage.getGenerationTokens() != null)
                ? usage.getGenerationTokens().intValue() : 0;
        return AiCallResult.<T>builder()
                .output(output)
                .promptTokens(promptTokens)
                .responseTokens(responseTokens)
                .latencyMs(System.currentTimeMillis() - startMs)
                .build();
    }

    private String buildPlannerUserPrompt(PlannerInput input) {
        StringBuilder sb = new StringBuilder();
        sb.append("请为以下候选人生成面试考纲：\n\n");
        sb.append("岗位：").append(input.getPositionName()).append("（").append(input.getPositionCode()).append("）\n");
        sb.append("工作年限：").append(input.getExperienceLevel()).append("\n");
        sb.append("面试模式：").append(input.getMode()).append("\n");
        if (input.getJobDescription() != null && !input.getJobDescription().isBlank()) {
            sb.append("JD 内容：\n").append(input.getJobDescription(), 0, Math.min(500, input.getJobDescription().length())).append("\n");
        }
        if (input.getResumeText() != null && !input.getResumeText().isBlank()) {
            sb.append("简历内容：\n").append(input.getResumeText(), 0, Math.min(1000, input.getResumeText().length())).append("\n");
        }
        if (input.getFocusTopics() != null && !input.getFocusTopics().isBlank()) {
            sb.append("候选人希望重点考察：").append(input.getFocusTopics()).append("\n");
        }
        sb.append("\n可考察的知识域列表：\n");
        if (input.getDomains() != null) {
            for (PlannerInput.DomainInfo d : input.getDomains()) {
                sb.append("- id=").append(d.getDomainId()).append(", code=").append(d.getDomainCode())
                  .append(", name=").append(d.getDomainName()).append("\n");
            }
        }
        return sb.toString();
    }

    private String buildQuestionGenUserPrompt(QuestionGenerationInput input) {
        StringBuilder sb = new StringBuilder();
        sb.append("请出一道面试题，要求如下：\n\n");
        sb.append("知识域：").append(input.getNextDomainName()).append("（").append(input.getNextDomainCode()).append("）\n");
        sb.append("题目类型：").append(input.getNextQuestionType()).append("\n");
        sb.append("目标深度：").append(input.getTargetDepth()).append("\n");
        sb.append("候选人岗位：").append(input.getPositionCode()).append("，年限：").append(input.getExperienceLevel()).append("\n");
        sb.append("面试模式：").append(input.getMode()).append("\n");
        if (input.getAskedQuestions() != null && !input.getAskedQuestions().isEmpty()) {
            sb.append("\n已问过的题目（避免重复）：\n");
            input.getAskedQuestions().forEach(q -> sb.append("- ").append(q.getStemSummary()).append("\n"));
        }
        if (input.getRagContext() != null && !input.getRagContext().isBlank()) {
            sb.append("\n【参考知识上下文，出题时可结合，不要直接引用原文】：\n").append(input.getRagContext());
        }
        return sb.toString();
    }
}
```

### 8.12 常见风险与应对

| 风险 | 现象 | 应对 |
|------|------|------|
| `BeanOutputConverter` 解析失败 | 模型未按 JSON schema 输出，`convert()` 抛异常 | system prompt 强调"严格按 JSON 格式，不输出额外文字"；保留 `extractJson` 正则作为 fallback |
| 兼容供应商 Usage 字段为 null | `getPromptTokens()` 返回 null，NPE | `buildResult()` 中已加 null 判断，降级为 0 |
| Spring AI BOM 与 Spring Boot 3.2.5 冲突 | 启动报 Bean 冲突或版本冲突 | Spring AI 1.0.0 要求 Spring Boot 3.2+，本项目满足；显式在 `dependencyManagement` 中锁版本 |
| 流式 SSE 在 Spring MVC 下断流 | 前端收到部分数据后连接中断 | 确认 `spring-boot-starter-webflux` 已引入；Controller 返回类型为 `Flux<String>` 且注解 `produces = TEXT_EVENT_STREAM_VALUE` |
| 向量库冷启动无数据 | RAG 检索返回空列表，出题无参考上下文 | `ragContext` 为空时 prompt 正常运行，不影响出题质量；知识库内容后续异步写入 |
